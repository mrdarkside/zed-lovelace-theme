# Zed theme schema

`zed-theme-v0.2.0.json` is an unmodified snapshot of Zed’s [official theme schema](https://zed.dev/schema/themes/v0.2.0.json), downloaded on October 17, 2026. Keeping it in the repository makes validation work offline after dependencies have been installed.

SHA-256: `c5a82ba7b133adfd48f60b88daa472d81ade95b78ce85e9a2ef2aef6ca2ba43e`.

When updating the schema, review the upstream changes, replace the snapshot, update this checksum and the validator’s version label, and run `pnpm check`.
